# Store Preservation Grants (work in progress)

Started 2026-11-19 at the owner's request: the Store's currency packages should give their currency through RETR0 as a **preservation grant**.

Owner's constraints:
- no real-money transaction is represented;
- no fake receipts;
- no Google Play Billing calls;
- no EA purchase infrastructure;
- the server decides the amount for a predefined package;
- no client-side-only balance edits.

The full brief is in the session of 2026-11-19 (Phases 1–9).

Status (2026-11-19): **working in the patched test build.** BUY on the currency packages and currency packs grants their contents through the game's own non-purchase award (SP-13..SP-15). It is tested live and survives a restart. The server-side gift channel works up to an unclaimed reward, but it froze the game twice, so it is parked (SP-11, SP-12).

## 2. Candidate design (to be confirmed by Phase 1)

1. **Server:** the RETR0 sync service gets a "grant" endpoint keyed by **package id/SKU**. The amounts come from the game's own static product list (SP-02), never from the client. Requests are authenticated, logged, and protected against duplicates by request id.
2. **Client, without faking a purchase:**
   - a Java hook on `NimbleMTX.purchaseItem(sku)` (redirect hook family, test emulator only) sends `{sku, request id}` to the RETR0 grant endpoint;
   - it reports the store transaction to the game as **not completed** (cancel/failure path), never as a payment;
   - the currency arrives through the game's own **award path** (SP-04), driven by the server.

   The catalog validation (SP-02) may need the hook to return catalog entries built from the static product list (names and amounts only, no prices or receipts) so BUY is enabled.
3. Currency then changes through the normal data flow and survives a restart. There are no client-only balance edits.

**Open questions:**
- how a server reply reaches `ProcessActionGrant` / `AwardProduct`;
- where `pMtxSkuList` and the package amounts live (static data file; Gold 16/42/87/183/476/1,019 from the screenshot), and the M$/R$ packages;
- the exact Java method signatures in JADX (`com/ea/nimble/mtx/*`);
- what the UI shows on cancel versus grant.
