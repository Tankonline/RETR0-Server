# Code of conduct

Project RETR0 is a small preservation community. Be the kind of collaborator you'd want to work with.

## Expected

- Be respectful and patient, especially with newcomers and people whose first language isn't English.
- Discuss evidence, not people. Disagree by bringing better evidence.
- Credit others' findings and work.
- Keep the project's rules: no game material, no personal data, no contact with EA infrastructure.

## Not acceptable

- Harassment, insults, discrimination, or personal attacks.
- Sharing anyone's personal information, accounts or credentials.
- Posting pirated game files, cracked APKs, or links to them.
- Using the project to cheat in or attack services that other people rely on.

## Enforcement

Maintainers may edit or remove content, and block contributors who break these rules. Report problems privately to
the maintainers through a GitHub security advisory or by contacting the repository owner on GitHub.
